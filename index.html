Assumes a hypothetical 1012 PBKDF2-SHA-512 guesses/second cracker — roughly 1000× the raw throughput of the fastest 2024 supercomputer applied to this KDF. Capped at the active-layer key space (1024 bits per active layer). Empty passphrases reduce both entropy and ceiling.
DataShield container (Q4X4) — 1024-bit layer keys via PBKDF2-HMAC-SHA-512 (600,000 rounds), 32-byte salts, four IVs, GCM tags, and per-layer canary tags for passphrase verification. AES is fixed at 256-bit width; 1024-bit material per layer is achieved by cascading four independent 256-bit subkeys. Files are held in memory during processing. Nothing leaves this browser.
